# Speechify Production Bug Register

This register documents all technical bugs, loopholes, race conditions, and numerical anomalies uncovered and resolved during the Production Hardening and Automated Technical QA pass.

| **BUG-016** | Timeline / Non-Destructive Placement | CRITICAL | (1) 'Add to timeline + project bin' placed enhanced audio directly on originating track using `overwriteClip`, destroying original source audio. | **BUG-017** | Timeline Placement Direction & Waveform Integrity | CRITICAL | (1) Timeline placement searched tracks above source (e.g. placing on A1 when source was on A2). (4) Output WAV signal validation was missing before Premiere import. | (1) Upward candidate loop (`0 ... sourceTrackIndex - 1`) selected empty tracks above source. | **BUG-019** | Range Processing / Job Generation | CRITICAL | Range processing (`Full Sequence` and `In / Out`) rendered entire sequence duration of selected tracks into continuous audio files, padding empty timeline gaps with silence, flattening waveforms across gaps, and placing monolithic sequence-length clips. | `isRangeTrackJob` in `plugin/index.js` treated each selected track as a continuous monolithic span (`targetStartTime = rangeStart`, `targetEndTime = rangeEnd`) and called `/api/audio/prepare-sequence` (`AudioPipeline.composite_timeline_audio`), artificially zero-padding empty gaps into continuous WAVs. | Replaced continuous track rendering with clip-based range architecture: (1) `ContextManager.buildEnhancementJobs` inspects actual `TrackItem`s on selected tracks and computes exact intersection `[effectiveStart, effectiveEnd]` with `[rangeStart, rangeEnd]`; (2) Empty timeline gaps produce 0 jobs and are never padded with silence; (3) Sliced clips compute exact `offsetFromClipStart` and slice `sourceIn = clipIn + offsetFromClipStart`; (4) `processSingleClipJob` passes clip coordinates directly to `/api/enhance`; (5) Sequential non-overlapping clips from same source track share destination track while leaving timeline gaps empty; (6) UI reports accurate count: `${totalClips} clips enhanced across ${numTracks} tracks`. | `tests.unit.test_clip_based_range_processing.ClipBasedRangeProcessingTests` (5 tests) & `tests/test_build_enhancement_jobs.js` | **FIXED** |
